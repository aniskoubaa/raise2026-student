RAISE 2026 — Day 1 Hands-On

From ROS 2 tools to an LLM agent that drives the robot · copy, paste, follow.

What you'll do: drive and sense the robot with a few commands (Lab 1.1), call each robot skill as a service, then let an LLM agent chain those skills to inspect a plant on its own (Lab 1.2). Every step is one command — press Copy, paste into a terminal, run.
Jump to: Setup Lab 1.1 · Drive & Sense Lab 1.1 · Call Skills Lab 1.1 · LLM Agent Lab 1.2 · Give a Mission Handy Commands Troubleshooting

0 · Before you start

1

Launch the greenhouse simulator

Open a terminal and start the sim. Leave this terminal running — open a new terminal for every command after this.

$ raise-sim
You should see: Gazebo opens with the greenhouse — a Husky robot, a UR5e arm, and rows of tomato plants.
2

Check your OpenAI key (needed for steps 09, 10, and Lab 1.2)

Steps 09, 10 and Lab 1.2 call an LLM. The key is auto-loaded from raise_ros2_ws/src/.env (a line OPENAI_API_KEY=sk-...). If those steps say "no API key", ask an instructor to add it — nothing else to do.

Every new terminal already knows the robot commands — the workspace is sourced for you via ~/.bashrc. Just open a tab and go.

1 · Lab 1.1 — Drive & Sense the Robot

topics: publish & subscribe

Each script opens a little menu. Follow the prompts; press Ctrl+C to quit and move on.

01

Drive the base

$ ros2 run raise2026_labs 01_drive_forward.py
Try: forward, back, rotate. Watch the Husky move in Gazebo.
02

Read the LiDAR

$ ros2 run raise2026_labs 02_read_lidar.py
Try: "nearest obstacle" — the distance changes as the robot faces a plant row.
03

Read the camera

$ ros2 run raise2026_labs 03_read_camera.py
Result: saves a frame to /tmp/raise_camera_frame.png — open it to see what the robot sees.
04

Aim the mast camera (PTZ)

$ ros2 run raise2026_labs 04_aim_ptz.py
Try: the look-around routine — the mast camera pans and tilts.

2 · Lab 1.1 — Call Each Skill as a Service

services = tools the LLM will use

These aliases do it all for you: they start the skill's server, run the client, and clean up when you quit. One word each.

CommandSkillWhat it does
05_d1Gripperopen / close / rotate the gripper
06_d1Armmove the UR5e to a named pose
07_d1Navigationdrive to a named waypoint (row 1, olive grove…)
08_d1Detectorrun YOLO object detection on a camera
09_d1Inspectorask a vision model for a plant-health verdict
05

Run a skill (example: the gripper)

$ 05_d1

Then try the others the same way:

$ 06_d1 # arm $ 07_d1 # navigation $ 08_d1 # detector $ 09_d1 # plant inspector (uses your API key)
09 says: a verdict like "healthy, confidence 0.88" — that reply is exactly what the agent will read next.

3 · Lab 1.1 — The Payoff: an LLM Chains the Skills

the agent loop
10

Start the agent (all 5 servers + the LLM orchestrator)

$ 10_d1

When it's ready, type a goal in plain English at the prompt, for example:

drive to tomato row 1 and tell me if the plant on the left is healthy
Watch: the LLM decides which tool to call, you see it navigate → aim → inspect, and it prints a final answer. That is an agent: LLM + tools + a loop.

4 · Lab 1.2 — Give the Robot a Whole Mission

autonomous inspection

Lab 1.1 took one goal. Lab 1.2's agent.py takes a mission and runs on its own — navigating, inspecting, recovering, and writing a report.

1

Start the 5 skill servers (one terminal, one paste)

$ ros2 run raise2026_tools gripper_server & $ ros2 run raise2026_tools move_to_pose_server & $ ros2 run raise2026_tools navigation_server & $ ros2 run raise2026_tools detector_server & $ ros2 run raise2026_tools inspector_server &
The & runs each server in the background so one terminal holds all five.
2

Run the agent

$ ros2 run raise2026_labs agent.py
Instructors may provide a one-command wrapper (d1l2_agentic_inspector.sh) that starts the sim, the 5 servers, and the agent together — use it if it's on your machine.
3

Type a mission at the mission > prompt

Inspect tomato row 1 on both sides and report which plants look unhealthy
Watch for: the step-by-step trace (Thought → Action → Observation), recovery when a view is blocked, and a field report written to /tmp. More missions in starter/mission_prompts.md.

Troubleshooting

Sim won't launch or hangs? Run raise-stop, then raise-sim from a fresh terminal.
Gazebo opens but says "Insert plugins to start!" (empty window, no robot)? A stale Gazebo GUI cache is loaded. Clear it and relaunch:
$ rm -rf ~/.gz/sim
$ raise-sim
The greenhouse and robot will now appear. (The red gz_frame_id / mimic-constraint warnings in the terminal are harmless.)
A skill server "not available"? Use the 05_d1…10_d1 aliases — they start the server for you. If you ran a script directly, its server must already be up.
Inspector says "unsure" / errors on 09 or 10? Check your OPENAI_API_KEY in raise_ros2_ws/src/.env, and make sure the arm is aimed at a plant.
Everything feels off after install? Run ./bootstrap/smoke_test.sh and read the pass/fail report.
